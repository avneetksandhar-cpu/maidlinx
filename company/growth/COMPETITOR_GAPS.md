## 1. Competitor framework

### 1.1 Competitor classes

| Class | Examples (illustrative) | Threat |
|-------|-------------------------|--------|
| National on-demand / marketplace | Handy, Taskrabbit, Angi/HomeAdvisor-type leads | Brand + “near me” demand capture |
| Vertical cleaning apps / rollups | Regional app brands, franchise maids | Local pack + recurring plans |
| Local agencies / maids | Independent GTA & SFL companies | Phone + Google reviews + GBP |
| STR / Airbnb specialists | Turnover-only cleaners | Host commercial keywords |
| Classifieds / gig | Kijiji, Craigslist, Facebook groups | Price-sensitive demand |
| Brooms & DIY content | Blogs, YouTube, Reddit | Informational SERP ownership |

### 1.2 Gap scorecard (per competitor / class)

Score each dimension 1–5 from **public** evidence only:

| Dimension | Question |
|-----------|----------|
| Booking UX | Can a stranger book online end-to-end in minutes? |
| Price clarity | Transparent estimate before pay? |
| Trust | Real reviews, clear company identity, insurance claims accuracy? |
| Coverage honesty | Do they over-claim cities? |
| Local SEO | GBP strength, location pages quality (not spam)? |
| Recurring / commercial | Plans for hosts, offices, PMs? |
| Supply quality signal | Vetted cleaners vs anonymous gig? |
| Mobile | Usable on phone? |

Then fill:

| Field | Purpose |
|-------|---------|
| WHAT THEY DO WELL | Steal the job-to-be-done insight — not the words |
| WHAT THEY DO POORLY | Friction MaidLinx can remove |
| CUSTOMER NEED | Jobs-to-be-done unmet |
| HOW MAIDLINX BETTER | Only claims true to shipped product |

## 2. Tier 1 — Toronto / GTA

### 2.1 Market context

- Dense condos + suburbs → recurring + move-out demand.  
- Competitive digital maids + agencies with strong GBPs.  
- Bilingual not required for core GTA English SEO; still multicultural messaging later.  
- MaidLinx **live** — may claim GTA zones that are active only.

### 2.2 Class gaps (directional)

#### National marketplaces (Handy / Taskrabbit-type)

| | |
|--|--|
| **WHAT THEY DO WELL** | Instant familiarity; app distribution; “near me” mental availability; fast quote UX patterns |
| **WHAT THEY DO POORLY** | Variable pro quality; fee opacity; weak local brand trust; support can feel offshore/generic |
| **CUSTOMER NEED** | Reliable cleaner, clear price, local accountability |
| **HOW MAIDLINX BETTER** | Market-scoped marketplace with admin assign + cleaner lifecycle (when MVP proven); CAD-native GTA positioning; honest service area vs “everywhere” |

*SERP share: RESEARCH REQUIRED*

#### Local GTA agencies

| | |
|--|--|
| **WHAT THEY DO WELL** | Google reviews; phone trust; recurring relationships; neighborhood reputation |
| **WHAT THEY DO POORLY** | Often phone/email quote only; slow book; weak after-hours; thin websites; limited STR productization |
| **CUSTOMER NEED** | Book tonight / this week without phone tag |
| **HOW MAIDLINX BETTER** | Online book → pay deposit path; status tracking aspiration via booking pages; multi-service catalog (deep, move, Airbnb, office) |

#### STR / Airbnb cleaners (GTA)

| | |
|--|--|
| **WHAT THEY DO WELL** | Host vocabulary; turnover SLAs; linen add-ons |
| **WHAT THEY DO POORLY** | Narrow offering; hard to find via generic “house cleaning”; inconsistent web presence |
| **CUSTOMER NEED** | Reliable turnover + same vendor for owner’s home |
| **HOW MAIDLINX BETTER** | Unified catalog: Airbnb SKU + residential under one booking engine; `/for-business` for multi-unit hosts (when ops ready) |

### 2.3 GTA SEO gap hypotheses

| Gap | Opportunity | Proof needed |
|-----|-------------|--------------|
| Agencies rank on GBP but sites are brochure-ware | Contentful market hub + service spokes | SERP sample |
| Few true on-demand UX brands local to GTA | Position “book cleaning on demand” honestly | Conversion test |
| Move-out / end-of-tenancy underserved digitally | `/services/move-out` + checklist content | Keyword volumes RR |
| Doorway spam from aggregators | Quality &gt; quantity pages; E-E-A-T via real ops | Manual review |

## 3. Tier 1 — South Florida

### 3.1 Market context

- STR / snowbird / condo density → turnover + seasonal spikes.  
- Fragmented local cleaners + national apps.  
- MaidLinx **live** — Miami-Dade / Broward / active FL zones only.

### 3.2 Class gaps (directional)

#### National marketplaces

| | |
|--|--|
| **WHAT THEY DO WELL** | Tourist/relocate familiarity; English UX; scale |
| **WHAT THEY DO POORLY** | Weak “South Florida” identity; inconsistent bilingual (EN/ES) support; quality variance |
| **CUSTOMER NEED** | Someone who knows condo access, humidity/mold-prone deep cleans, STR turnovers |
| **HOW MAIDLINX BETTER** | Explicit South Florida market hub; Airbnb + deep + move SKUs; US/USD checkout path |

*SERP share: RESEARCH REQUIRED*

#### Local SFL agencies / maids

| | |
|--|--|
| **WHAT THEY DO WELL** | Hyperlocal GBP; Spanish-capable staff (many); host referrals |
| **WHAT THEY DO POORLY** | Cash/Zelle informal booking; limited online deposit; sparse multi-city honesty |
| **CUSTOMER NEED** | Trusted book-online with deposit + messageable status |
| **HOW MAIDLINX BETTER** | Stripe deposit + structured booking details (access notes); marketplace vetting goal |

#### Airbnb turnover specialists (Miami / FLL)

| | |
|--|--|
| **WHAT THEY DO WELL** | Same-day turn marketing; host WhatsApp ops |
| **WHAT THEY DO POORLY** | SEO thin; dependency on Airbnb message leads; little residential cross-sell |
| **CUSTOMER NEED** | One vendor for turnover + owner cleans |
| **HOW MAIDLINX BETTER** | Productized Airbnb service + residential cross-link; business page for host portfolios |

### 3.3 SFL SEO gap hypotheses

| Gap | Opportunity | Proof needed |
|-----|-------------|--------------|
| “South Florida” regional head term less owned than “Miami” | Hub page targeting regional + city sections | SERP RR |

Use in copy only when product/ops support:

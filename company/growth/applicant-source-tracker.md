## How to use

1. When an `/earn` application arrives, add one row the same day.
2. Ask “How did you hear about us?” in screening if missing.
3. Weekly loop: which channel produced apps? Kill silent channels; double down on converters.
4. Do **not** open booking or Stripe LIVE based on application volume alone.

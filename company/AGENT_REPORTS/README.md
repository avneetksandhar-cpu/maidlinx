# Agent reports

Role agents leave short reports here after significant work.

## Naming

`YYYY-MM-DD-<role>-<topic>.md`

Examples:

- `2026-08-11-qa-security-mvp-gate.md`
- `2026-08-11-lead-engineer-stripe-webhook.md`

## Template

```markdown
# <Role> — <topic>

- Date:
- Sprint ref: company/CURRENT_SPRINT.md
- Summary:
- Evidence / links:
- Blockers:
- Asks (Product / Lead Engineer / QA):
- Secrets: none (never paste keys)
```

## Rules

- No secrets, tokens, or `.env` contents
- Prefer checklists and handoffs over long essays
- Do not claim metrics without a source

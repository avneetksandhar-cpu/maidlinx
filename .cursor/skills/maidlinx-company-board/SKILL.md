# MaidLinx company board

## Before substantive work

1. Read `AGENTS.md`
2. Read `company/CURRENT_SPRINT.md` (CRITICAL MVP gate)
3. Skim `company/ROADMAP.md` and `company/DECISIONS.md` if scope is unclear

## Board paths

- `company/ROADMAP.md`
- `company/CURRENT_SPRINT.md`
- `company/METRICS.md`
- `company/DECISIONS.md`
- `company/AGENT_REPORTS/`

## Rules

- No secrets in board files
- No scope expand until CRITICAL checklist passes
- After significant role work, add a short report under `company/AGENT_REPORTS/`
- Prefer role subagents in `.cursor/agents/` — see `AGENTS.md` for invocation
